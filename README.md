# Petrol Expense Calculator

A simple and responsive web application to calculate petrol fuel cost based on travel distance, vehicle mileage, and current petrol price.

🔗 **GitHub Repository**: https://github.com/aSHU-dEv-stack/Petrol-Expense-Calculator

---

## 📋 Project Overview

Petrol Expense Calculator is a lightweight frontend project that helps users quickly estimate their total fuel expense for a trip or daily commute.

Users simply enter:

- Distance to travel (in kilometers)
- Vehicle fuel efficiency (km per litre)
- Current petrol price (per litre)

The application then calculates:

- Fuel required (in litres)
- Total petrol cost

This project demonstrates JavaScript logic building, DOM manipulation, and form handling using pure HTML, CSS, and Vanilla JavaScript.

## 💡 Key Components

- **Distance Input**: User enters total travel distance in kilometers  
- **Mileage Input**: Vehicle efficiency in km per litre  
- **Petrol Price Input**: Current price per litre  
- **Calculation Logic**:

```
Fuel Required = Distance ÷ Mileage  
Total Cost = Fuel Required × Petrol Price
```

- **Result Display Section**: Shows fuel needed and total expense clearly
